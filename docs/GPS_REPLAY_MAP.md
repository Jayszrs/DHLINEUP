# GPS fleet replay

The speed dashboard now displays a large geographic map instead of parked fleet rows. Satellite imagery comes from the public Esri World Imagery tiled service, with attribution in the map. OpenStreetMap and a plain GPS-track view are alternatives. All application JavaScript and the Leaflet library are served locally. Tile requests carry tile coordinates only; application records, driver identities and raw GPS files are not sent to the imagery service.

The historical replay reads the selected date's original Location, Creation Time and Speed values. Routes are sampled to at most 240 original fixes per DT/day for a bounded response. The truck interpolates only between moving fixes at most 120 seconds and 60 metres apart; otherwise it holds the last observation. The label reports the last sampled GPS speed, not the daily average. A unit report retains the daily weighted average, moving average and maximum. Missing observations, gaps over 900 seconds, equal-time conflicts and implausible jumps split paths and are never joined by a continuous journey.

All globally valid coordinates remain in the private source payload, including distant points. Initial framing focuses on the observed local cluster. The map can pan or focus an individual unit to inspect other recorded positions. Satellite imagery can be newer or older than the selected historical date and is not represented as a historical photograph of that day.

The initial package covers October 1–31, 2026: 5,702,740 available source GPS rows, 23,858 rows with unusable locations, and 867,716 retained map fixes. Legacy single-digit hours and Indonesian formatted speed values are accepted. October 23 has 214 DTs with usable GPS. Earlier dates can have fewer GPS units than recap units because the earlier source archives do not contain every historical reading; this difference is shown as separate counts.

`node backend/cli/build-speed-map.js` builds `.private/speed-map-package`; `--apply` uploads compressed archives to the existing private bucket and writes the `speed_map_index` setting. The builder validates the source checksums, recap values, versions and GPS archive paths against the database. The `/speed-map-data?date=YYYY-MM-DD` endpoint requires the normal application session. It checks a per-date fingerprint and payload digest before returning data. If a later manual edit or GPS import changes that date, the old cached replay is withheld until rebuilt. Source GPS and recaps are never modified by this builder.

The map supports a WIB timeline, replay-rate selection, unit search/selection, zoom, framing, scale, and full-screen expansion. It suspends animation offscreen/in a hidden tab and respects reduced motion. The owner explicitly requested removal of pause buttons from all visuals. Camera/zoom and date/report controls remain available.

The OCC model now has exactly four front and four back workstation setups, facing the front video wall, behind a rectangular U conference table, open toward the video wall. It has twelve meeting chairs (four left, four across the connecting side, four right), a central Kandao pedestal, a PTZ above the videotron, and six ceiling speakers. Geometry is illustrative, following the supplied room photograph and the owner's requested arrangement. Source inventory totals remain unchanged. Driver and truck models add rounded safety helmets, reflective clothing, cab/tire/grille/rail details and shared vertex-colored geometry.

Direction: map-first monitoring with one bounded moving surface. ENERGY 2 / RHYTHM 2 / MOTION 2; neutral application chrome, readable white overlays, orange/gold equipment identity, green movement and amber stopped indicators. No pause control is included per the user's explicit preference.

On the map, nearby historical positions are clustered at every scale to prevent overlapping equipment. Clusters use stacked truck sprites instead of numeric bubbles. Clicking zooms their bounds; at close zoom, a unit picker makes coincident DTs individually accessible. The selected truck stays separate. GPS route lines are no longer drawn, including for the selected DT. The route checkbox is removed; historical positions, movement, selection, clustering and 3D previews remain. The unit list opens in a separate column rather than covering the mine. Road tiles explicitly use a normal `strict-origin-when-cross-origin` image referrer policy, as required by the OpenStreetMap tile policy; errors return the display to satellite imagery. No proxying, fabricated referrer or tile bulk fetching is used.

Clicking a truck or a Line Up label opens a rotatable, zoomable 3D preview with the corresponding real date, identity and measurements/status. Map replay and preview wheel movement continue while the preview is open. The preview respects reduced motion. The OCC room has forty-two object hit regions, including all twenty chairs and eight desks, three U-table sections, videotron, Kandao, PTZ and six speakers, plus the IT and Engineer side rooms behind glass partitions. Object selection also works through a labelled dropdown. Furniture is explicitly identified as illustrative rather than presented as an extra inventory record. Preview details keep master asset availability separate from daily inspection status.

Replay now starts at real-time 1x; faster rates remain available. The map minimum zoom allows global context. Scene and object viewers expose zoom-out, zoom-in, reset and fullscreen controls. Static dashboard charts, metric groups, period summaries and tables receive the same controls without changing their data or link actions.

The selected truck preview uses a repeating 3D haul road with gravel shoulders, berm rocks and safety posts. Road travel and wheel rotation derive from the currently displayed GPS speed in km/h, converted to metres per second, with zero-speed and reduced-motion states staying still. The environment is labelled illustrative; it is not another geographic reconstruction. The videotron uses an illustrative conference/operations display, explicitly marked as not a live broadcast. Side-office geometry is illustrative and does not add inventory rows.

The owner chose an explicitly illustrative parking area. Operational mode moves stopped units, units with no observation at the selected time, and held observations over 90 seconds old into a separate parking panel. The last two states are labelled GPS unavailable / observation gap, not assumed stopped or assigned a workshop status. The panel has real recap unit IDs, search, pagination and a 3D parking preview. This does not change source coordinates, speed values, daily recaps or geofences. All GPS positions mode retains geographic inspection of the original available fixes. No actual workshop location is inferred from satellite imagery.

Playback geometry is implemented in the pure frontend fleet-playback module. Sparse long-distance samples no longer generate a long straight-line drive across unobserved terrain. Parking preview wheels stay still, including when a held historical speed is positive; the terrain follows the display state while the reported last GPS speed remains intact.
